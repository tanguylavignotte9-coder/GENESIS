# Rapports du banc d'essai

Ce dossier reçoit les rapports du **banc d'essai** de GENESIS, lancé :

- par un double-clic sur `Benchmark-GENESIS.bat` (à la racine du jeu) ;
- ou dans le jeu : Atelier des variables (touche **F2**) › « Lancer le banc d'essai ».

Chaque lancement écrit deux fichiers datés, par exemple `banc-essai_2026-11-18_14-05-09.txt`
(lisible) et `.json` (pour Claude Code) : processeur, nombre de cœurs, mémoire, version de Windows,
puis, pour 100 à 5 000 humains, le temps de calcul d'un jour de jeu et la vitesse maximale tenable.

Le dossier est versionné : pour transmettre les résultats, validez (commit) les nouveaux fichiers avec
GitHub Desktop puis poussez-les (push).
